一汽丰田汽车销售有限公司
　　将飞机，火车和汽车抛在脑后，在互联网上做培训服务，经销商和客户可以点播多媒体的网络课件，或者产品演示，这一切仅需要一个 WEB 浏览器。实际上，如果你教会技术支持人员使用 WEB 浏览器，您甚至可以提供在线技术帮助，从而减少了电话通信费用和不满意客户的数量。

　　一汽丰田汽车销售有限公司（以下简称一汽丰田），一个在全国有两百多家经销店的汽车销售公司，就是一个很好的例子。一汽丰田向全国范围内的经销店提供产品的销售培训、维修技术培训和管理培训，购买产品的客户根据经销店的演示决定是否买一汽丰田的产品。过去，一汽丰田派遣一支队伍，要对每个经销店寻访一次或多次。“我们每月出差大约 8 次，费用高达 10 万元。” 一汽丰田市场部经理， Mike Chan 说道，“我们陷于既要增加销售，又要降低开支的窘境中。而且，我们想缩短销售周期，即两次培训之间的时间为 6 到 12 周。” 这时，公司发现了 ESS 自助学习系统。

　　应用 ESS 系统，首先免除了为一汽丰田建立站点的大笔费用，收取 50000 元 / 年的系统维护和支持费用，用于提供在线培训平台和共享公共课程服务。（相比之下，比如 北京某公司 的 zj 网络教学平台费用 则大为减少。）但基于 Web 的解决方案获益于长期的使用。

　　“ zj 网络教学平台 是一个好的工具，但并非适于所有场合。我们的客户不一定装有它或会使用它，” Mike Chan 说。相比之下， ESS 系统的使用只需要 web 浏览器， 普通的 ADSL 或更高速率的 Intenet 连接，使用者只需从 ESS 站点下载一个小插件。一旦自动安装上这种插件，所有使用者都能够观看产品演示和培训。

　　现在，一汽丰田公司在同样数量的员工参与下，可以完成 3 倍以上的产品培训任务。其中一半是在网上进行。尽管另一半的培训和演示仍由人来主持，但只需派遣一人出差。维修技术员可以通过 ESS 系统在家中或办公室里做演示。一汽丰田缩短了一半的销售周期，由原先的 6 个月减至 3 个月。

　　一汽丰田也将 ESS 用于技术支持，这点在与强手竞争中显得尤为必要。现在一汽丰田技术员只需坐在办公室里，在线观察用户提供的故障现象，就可解决问题。一汽丰田每月在销售差旅费和技术支持费上节省了大约 30 万元。
